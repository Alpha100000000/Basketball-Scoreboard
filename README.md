# 🏀 Basketball Scoreboard

A simple **interactive basketball scoreboard web application** built with **HTML, CSS, and JavaScript**.
This project simulates a real basketball scoreboard with scoring controls, a game clock, shot clock, period tracking, and a winner screen.

---

# 📌 Features

### Score Tracking

* Home and Away team scoreboards
* Add **+1, +2, or +3 points**
* Real-time score updates

### Game Clock

* 12 minute game clock
* Start / Pause / Reset controls
* Automatically stops when the game ends

### Shot Clock

* 24 second shot clock
* Start / Pause controls
* Reset to **24 seconds** or **14 seconds**

### Period Tracking

* Tracks game periods
* Next period button

### Winner Overlay

When the game clock reaches **0:00**:

* Displays **Home Wins**, **Away Wins**, or **Tie Game**
* Shows final score
* Options to start a **New Game** or **Close**

### Reset Game

Quickly reset:

* Scores
* Period
* Game clock
* Shot clock

# 🚀 How to Run the Project

1. Download or clone the repository:

```
git clone https://github.com/YOUR-USERNAME/basketball-scoreboard.git
```

2. Open the project folder.

3. Open **index.html** in your browser.

That’s it — the scoreboard will run locally.
